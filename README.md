# NEWERA 🚀

NEWERA is my personal programming and software development repository, documenting my journey from foundational programming concepts to data structures, algorithms, and practical software projects.

The repository combines consistent coding practice with hands-on implementation of algorithms and tools designed to solve real-world problems.

## 🎯 Objectives

- Strengthen programming fundamentals through practical implementation.
- Develop problem-solving skills using Data Structures and Algorithms (DSA).
- Practice writing readable, modular, and efficient code.
- Build useful Python applications that address everyday problems.
- Learn Git and GitHub for version control, collaboration, and project management.
- Track progress through meaningful code contributions and continuous improvement.

## 🧠 Data Structures and Algorithms

Topics explored include:

- Arrays, strings, and two-pointer techniques
- Sliding window algorithms and binary search
- Stacks, queues, heaps, and monotonic stacks
- Linked structures, trees, and graph algorithms
- Breadth-First Search (BFS) and Depth-First Search (DFS)
- Shortest-path algorithms: Dijkstra, Bellman–Ford, and Floyd–Warshall
- Minimum spanning trees: Prim's and Kruskal's algorithms
- Dynamic programming and backtracking
- Disjoint Set Union (Union-Find)
- Tries, segment trees, and Fenwick trees
- Bit manipulation and bit masking
- Topological sorting and strongly connected components
- Advanced interval, heap, and graph problems

## 🛠️ Practical Projects

The repository also contains hands-on programming projects, including:

- **URL Shortener:** Generates short codes for URLs, with persistent storage and URL management.
- **Blackjack Game:** Implements card handling, gameplay, and score tracking.
- **Maze Solver:** Explores grid traversal and pathfinding.
- **Repository Statistics Tool:** Works with GitHub repository data and API responses.
- **GitHub Contribution Assistant:** Inspects the current Git repository, displays recent commits, checks working-tree changes, and compares the local branch with its configured remote.
- **File and Data Utilities:** Practice file handling, JSON persistence, and data processing.
- **Networking Experiments:** Explore client-server communication using Python sockets.
- **Data Visualization:** Practice creating charts and working with Python libraries.

Projects evolve as new features, error handling, and better implementations are added.

## 📈 Development Approach

I focus on learning by building: implementing algorithms from scratch, debugging errors, understanding time and space complexity, and gradually extending projects with practical features.

The repository reflects ongoing learning rather than a collection of finished production applications. Code is refined as my understanding and development skills improve.

## 🔄 Workflow

1. Write and test code in VS Code or GitHub Codespaces.
2. Use Git to track changes and maintain project history.
3. Commit meaningful updates.
4. Push changes to GitHub.
5. Review, improve, and extend existing implementations.
